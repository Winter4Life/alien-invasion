# Alien Invasion

> A 2D alien shooter built in Pythin using the Pygame package.
> Shoot down a fleet of aliens as each level increases in speed and difficulty.
>
> Players control a rocket ship that appears in the bottom center of the screen.
The user can move this ship left or right using the left and right arrow keys and shoot
lasers using the spacebar. As the game begins, a fleet of aliens fill the sky and move
across and down the screen. When the player hits a target, the alien is destroyed. If
the player is able to destroy all the aliens, a new fleet with appear with increased
speed and difficulty than the previous fleet. If the fleet hits the players ship or
reaches the bottom of the screen, the player loses a ship. If the player loses all
three ships, the game ends.
